# Hai Yin I 两层生活区与机舱内部

2026-11-19。本次在独立 `/vessels/hai-yin-i` 和单文件 `standalone/Hai_Yin_I_Atlas.html` 中加入可进入的内部；原教学船 `/atlas` 保持独立。

## 操作

- `Accommodation 一层` / `Accommodation 二层`：进入相应楼层，拖动画面可水平无限环视，俯仰有限制，避免倒置。
- 点画面后用方向键或 WASD 前后左右移动；Q / E 转向。手机长按屏幕方向按钮，也可拖动环视。
- `去楼梯上楼 / 下楼`：定位至对应楼梯平台，再向前行走，沿简化踏步连续改变高度。楼层按钮提供直接定位。
- 房间菜单是虚拟定位。CO₂ 瓶间、蓄电池室、充放电室及空调室等原图独立外门房间，不通过伪造的内门连接到走廊。
- `Engine Room 第一视角`：进入机舱通道；`退出第一视角` 恢复整船轨道相机。第一视角中点选器材只高亮和显示说明，不将镜头拉回船外。
- `消防布置`：显示局部消防器材与 CO₂ 系统符号。消防系统仅用于布置学习，没有真实启动、释放或应急操作功能。

## 几何范围及精度

一层：厨房、餐厅、公共卫生间/淋浴、CO₂ 瓶间、两间船员室、机舱围井及楼梯间。二层：两间船员室、蓄电池室、充放电室、空调室及楼梯间。住宿层为两层，驾驶室是另外的上层空间，不将驾驶室算成第三层住宿。

机舱：FR6–17 内部舱壁、平台、双主机、两主机之间的发电机组、300×240 mm 通风管段和格栅、双消防泵示意，以及部分灭火器、报警按钮、水带箱与消火栓。FR17–20 的泵舱与两舷柴油舱仍按独立部位处理，不将其误当住宿空间。

全部单位为米，但**米制比例不是全部施工几何已完成 1:1 的证明**。房间边界和设备纵向位置按图投影量取；机舱行走平台 BL+1.42 m 是剖面比例估值。门洞宽度来自原表；虚拟行走自动跨越门槛。家具平面参考原图，但床、桌、椅、橱柜高度、饰面、设备外壳和楼梯踏步细节属于简化表达。没有把家具颜色、普通泵壳或管路猜测标为厂家 CAD。

最新消防完工图中消火栓 / 水带箱各 8，规格书第 16 页有 9 的记录。模型采用较晚完工图作为布置依据，差异单独登记。CO₂ 瓶组用一套符号表示，示意瓶不代表实际瓶数。消防器材尚未逐件覆盖全船，完整管路、阀件、支架、探测/报警线路和所有厂家附件仍未完成。

## 性能与验证

继续只加载一个 Hai Yin I GLB；静止时采用 demand 渲染。行走或转向按需恢复帧，松键、取消触摸、失焦、切后台均释放移动状态。使用连续小步碰撞，防止长帧穿墙；楼梯只能从两端进入，不从侧边穿楼板。DPR 有上限，阴影关闭，切回二维或卸载时释放 GPU 资源。

`npm test` 22 项通过，含门洞通行、船员室隔墙/外边界、楼梯上下层、房间定位点、消防来源和选择保持第一视角。`npm run build` 完成 343 页与 TypeScript 检查。Chrome 实测网页和离线 HTML 的方向移动、超过 360° 的连续拖动环视、上下楼、两层房间切换、机舱进入/退出、第一视角中选主机保持镜头、390 px 屏幕长按方向按钮、键盘激活按钮后松键停走、失焦停走、静止停止绘制，以及切二维释放 Canvas 后恢复第一视角。离线 HTML 无 HTTP 请求；两种入口无浏览器脚本错误。
