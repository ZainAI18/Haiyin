# 两艘独立船与 Hai Yin I 整船装配状态

更新日期：2026-11-18。

网站有两个独立船舶页面：

| 船舶 | 路由 | 模型与用途 |
|---|---|---|
| 原有教学参考船 | `/atlas` | 原有示意船和 334 项学习术语，保留原几何、焦点和场景 |
| MT Hai Yin I | `/vessels/hai-yin-i` | 独立米制 GLB、独立部件编号和图纸来源；按其自身资料建模 |

教学船已有的舵、锚、桨等部件不会从 Hai Yin I 中省略。三组文件字节重复只在来源台账中归并；真实存在的双机、双轴、双桨、双舵和左右舷舱室分别保留实例。

## 当前已有的整船几何

Hai Yin I 可视化装配包含：闭合插值船壳、球鼻艏近似横剖面、主甲板、艏楼、三层艉楼与驾驶室、主要横舱壁、八个货油舱包络、双舷压载舱包络、双主机及齿轮箱、双轴、双四叶桨、双舵、辅助发电机组包络、锚机和双锚示意、输油臂、舱口、通气和系泊件、栏杆、救生筏及桅杆。

资产：`public/hai-yin-i/models/hai-yin-i-visual-assembly.glb`，约 1.19 MB、171 个网格节点、28,440 个三角面。页面提供 32 个定位目标，外观 / 透视 / 货油舱 / 机舱四个预设。选择内部件时自动打开对应可见层并聚焦；点击模型也可选择。原教学船不加载这个 GLB。

## 1:1 的已落实部分与未完成部分

统一采用米，1 GLB 单位 = 1 m。较新 B 版总结构图的甲板和艏楼矢量线按肋距与型宽标定。纵向以 FR20–FR34 的 14 × 560 mm 为基准，横向以 9.80 m 型宽为基准；标定后的艏楼艉缘约为 FR77，主甲板长度约 48.596 m，加艏部前伸得到总长 49.90 m。

双轴横向位置 ±2.500 m、轴线 BL+0.950 m、舵叶 1.400 × 2.080 m、桨径 1.730 m、四对货油舱肋位等有原图参数。

**整船可浏览仍不等于全部细节已实现 1:1。** 船壳横剖面目前采用圆舭与轮廓插值；艉轴隧道、球鼻艏横剖面、所有肋骨与加强材、舱壁开孔、厂家设备精确外壳、焊缝及 2019 改装走管尚未全部复原。机舱和部分甲板设备为包络或示意，柴油舱圆球仅为位置标记，默认不在机舱总览中显示。它们都在 `ship-assembly.json` 和点选说明里保留精度分类，未标为厂家精确 CAD 或制造完成模型。

2019 货油改装系统图为 N.T.S.，系统连接关系不能提供全部三维管路坐标；厂家外形与现场待定尺寸也不能用通用模型猜成精确数据。进一步完成全部 1:1 细节，需要继续核对逐站型线与厂家尺寸图，补足没有给出的施工几何。

## 本次验证

- `npm test`：17 项通过，包含原术语映射、独立船舶资产、八个货油舱、双推进、两只舵复用同一部件定义、内舱选择与共享材质隔离。
- `npm run build`：通过，TypeScript 和 343 个生成页面完成。
- 网站 Chrome 实测：原教学船的锚、桨焦点保持工作；来回切换两个船舶页面，Hai Yin I 单独加载整船资产；32 个目标均可选择，四个查看预设改变实际渲染，模型点选命中正确部件，390 px 视口无页面溢出。
- 离线 HTML：默认显示整船；32 个目标、点选、四种查看预设、四种视角、复位、网格、整船下载、二维资源释放、真实 WebGL 上下文丢失及无 WebGL 降级均通过，零 HTTP 请求。
- 静止时停止提交绘制；聚焦动画结束后停止渲染。相机复位不重建 Canvas，不重新加载模型。
